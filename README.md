# 大學課程作業與專題

收錄我在大學期間的程式作業、實驗與專題，包含網頁設計、微控制器、物聯網、FPGA、平行程式與影像處理等課程。

## 課程內容

| 課程 | 內容 | 使用技術 |
|---|---|---|
| [網頁設計](webp/README.md) | 介紹頁、打字遊戲、API 串接與 React 元件練習 | HTML、CSS、JavaScript、jQuery、React |
| [行動裝置程式設計](mobile-programming/README.md) | CH01～CH08 Android 練習與飲料點餐期末作業 | Java、XML、Android Studio |
| [物聯網](iot-alarm/README.md) | 超音波測距、LCD 顯示與 LED 警示 | ESP8266、MicroPython |
| [微算機實驗](microcontroller-labs/README.md) | 按鍵與 LED 控制、計時器、GLCD 貪食蛇 | C、組合語言、C8051F040 |
| [FPGA 實驗](fpga-labs/README.md) | 邏輯電路、雙人骰子遊戲與資料路徑 | Verilog、Quartus |
| [平行程式設計](parallel-programming-labs/README.md) | 程序間通訊、平行計算 π 與耗時比較 | C、MPI、OpenMP |
| [多媒體資訊概論](multimedia-labs/README.md) | WAV 聲音產生、邊緣偵測、影像對比增強與假色圖 | C++、Python、OpenCV |
| [計算機架構](computer-architecture-labs/README.md) | MIPS 指令解析與機器碼欄位編碼 | C++ |
| [計算機網路](cpp-http-downloader/README.md) | HTTP 網頁與圖片下載 | C++、Winsock |
| [C++ 與資料結構](cpp-coursework/README.md) | 大一上下 Lab、遞迴、指標、文字對齊與排序效能比較 | C++ |
| [MATLAB 練習](matlab-labs/README.md) | 矩陣、求根、數值積分與傅立葉級數 | MATLAB |

各資料夾的 README 列有作業內容、主要檔案與開發環境。
