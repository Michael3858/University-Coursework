# 計算機架構作業

大學計算機架構課的兩份 C++ 作業，從讀懂 MIPS 指令格式，進一步練習把指令拆成機器碼欄位。

## 作業內容

| 作業 | 在做什麼 | 主要檔案 |
|---|---|---|
| Project 1 | 解析 `add`、`sub`、`lw`、`sw`，檢查暫存器格式，列出來源與目的運算元。 | [B0929035_林品翰_CAProject1.cpp](Project1/B0929035_%E6%9E%97%E5%93%81%E7%BF%B0_CAProject1.cpp) |
| Project 2 | 解析更多 MIPS 指令，輸出 opcode、暫存器編號、立即數等二進位欄位。 | [B0929035_林品翰_CAProject2.cpp](Project2/B0929035_%E6%9E%97%E5%93%81%E7%BF%B0_CAProject2.cpp) |

## 開發環境

C++11 或更新的編譯器。兩支程式各有自己的 `main()`，要分開編譯。

## 輸入範例

`add $t0,$t1,$t2`

Project 1 會列出指令名稱、來源與目的運算元；Project 2 則輸出對應的編碼欄位。輸入格式需符合程式的檢查條件，例如逗號後不加空白。
