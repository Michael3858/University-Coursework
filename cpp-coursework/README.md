# C++ 課程作業

大學 C++、離散數學與資料結構課的四份作業，包含遞迴、動態記憶體、文字處理與排序。

## 開發環境

每支 `.cpp` 都有自己的 `main()`，要分開編譯。原本的編譯器版本沒有留下紀錄。

排序比較使用 Windows 的 `QueryPerformanceCounter` 計時；部分作業使用變動長度陣列，標準 C++ 編譯器不一定接受。

排序比較可選擇 1、2、3，分別測量合併排序、堆積排序與插入排序，資料量從 10 到 100,000 筆。

部分程式仍有需要修正的地方：遞迴作業的合併排序有陣列邊界問題，動態陣列作業有釋放索引錯誤；文字對齊程式則假設每行都有空格。
