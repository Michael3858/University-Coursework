# HTTP 網頁與圖片下載程式

大學計算機網路課的作業，使用 C++ 和 Winsock 連線到網站，送出 HTTP GET 請求，下載網頁和其中的圖片。

主要程式是 [pro1.cpp](pro1.cpp)。

## 程式在做什麼

1. 讀入網址和要儲存檔案的資料夾名稱。
2. 透過 TCP 連到主機的 80 port，取得網頁內容。
3. 從網頁的 `src` 屬性找圖片，逐一下載並改成本機檔名。
4. 將網頁存成 `Michael.html`，顯示檔案數、總容量和花費時間。

程式可以互動輸入，也能由命令列傳入「網址、資料夾名稱」兩個參數。儲存資料夾必須先建立。

## 開發環境

C++、Windows Winsock。程式同時引用 `pthread.h`、`unistd.h` 和 Windows 標頭，需要支援這些介面的工具鏈；專案未附編譯設定。

連線固定使用 80 port，僅支援 HTTP。HTML 與圖片網址採用簡單的字串解析，可能需要依網頁格式調整。
