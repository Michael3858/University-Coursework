# 微算機實驗

大學微算機實驗課的作業與期末專題，使用 C8051F040，以組合語言和 C 撰寫。

期末專題是 GLCD 貪食蛇，用按鍵控制方向，包含食物生成、分數顯示與撞牆處理，基本版程式為 [`final/test8.c`](final/test8.c)。

## 作業內容

| 資料夾 | 在做什麼 |
|---|---|
| [Lab1](Lab1) | 組合語言陣列讀取、乘法與累加。 |
| [Lab2](Lab2) | 按鍵輸入與 LED 控制。 |
| [Lab3](Lab3) | 用 Timer0 中斷控制 LED。 |
| [Lab4](Lab4) | 改用 C 撰寫按鍵、計時器與不同 LED 移動模式。 |
| [Lab6](Lab6) | GLCD 初始化、讀寫與按鍵繪圖。 |
| [Lab7](Lab7) | 用計時器產生不同音高與旋律，另保留 LCD 延伸版本。 |
| [final](final) | GLCD 貪食蛇，包含基本版與兩個延伸版本。 |

## 程式導覽

- `final/test8.c`：基本版。`button_detect()` 讀取方向，`resetSnake()` 重設位置，GLCD 相關函式負責畫面輸出。
- `final/bonus1.c`、`final/bouns2.c`：調整遊戲狀態、開始／結束畫面與撞牆處理的版本。`bouns2` 是原本的檔名。
- `glcd.h`：GLCD 控制位元與函式宣告，隨各作業保留。

## 開發環境

C8051F040 開發板、按鍵／LED，以及期末專題使用的 GLCD。程式含 `sbit`、`interrupt` 等 8051 C 語法，需要相容的 8051 工具鏈，不能直接用一般桌面 C 編譯器編譯。

程式引用的 `C8051F040.h` 與 `Lab7/bouns2.c` 使用的 `LCD.h` 未包含於專案，需由對應開發環境補齊。`C8051F040_defs.h` 是暫存器定義參考，無法直接替代上述標頭檔；執行前也需確認實際接線。
