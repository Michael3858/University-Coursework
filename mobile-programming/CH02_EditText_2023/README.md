# 姓名輸入與問候

行動裝置程式設計課程練習。讀取姓名輸入欄，顯示問候文字，並保留文字大小調整按鈕。

## 主要檔案

| 檔案 | 內容 |
|---|---|
| [MainActivity.java](app/src/main/java/tw/cgu/b0929035/ch02_edittext_2023/MainActivity.java) | 畫面事件與程式邏輯。 |
| [activity_main.xml](app/src/main/res/layout/activity_main.xml) | 主畫面元件與版面。 |

## 開發環境

Java 8 語法、compile／target SDK 32、最低 SDK 26；Android Gradle Plugin 7.2.1、Gradle 7.3.3。使用 Android Studio 開啟本資料夾。
