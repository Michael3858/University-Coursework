# 表單與密碼比對

行動裝置程式設計課程練習。讀取姓名、系級與電話，通過教學用固定密碼比對後顯示資料。

## 主要檔案

| 檔案 | 內容 |
|---|---|
| [MainActivity.java](app/src/main/java/tw/cgu/b0929035/ch03_confirmidpw/MainActivity.java) | 畫面事件與程式邏輯。 |
| [activity_main.xml](app/src/main/res/layout/activity_main.xml) | 主畫面元件與版面。 |

## 開發環境

Java 8 語法、compile／target SDK 32、最低 SDK 26；Android Gradle Plugin 7.2.1、Gradle 7.3.3。使用 Android Studio 開啟本資料夾。

密碼比對為本機課堂練習，使用範例值 `demo-pass`。
