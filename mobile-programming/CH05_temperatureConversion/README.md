# 攝氏與華氏換算

行動裝置程式設計課程練習。用 RadioGroup 切換輸入單位，透過 TextWatcher 即時顯示攝氏與華氏結果。

## 程式導覽

| 檔案 | 內容 |
|---|---|
| [MainActivity.java](app/src/main/java/tw/cgu/b0929035/ch05_temperatureconversion/MainActivity.java) | 主要畫面與事件處理。 |
| [activity_main.xml](app/src/main/res/layout/activity_main.xml) | 畫面配置。 |

## 開發環境

Java 8 語法、Android Gradle Plugin 7.2.1、Gradle 7.3.3，compile／target SDK 32，最低 SDK 26。使用 Android Studio 開啟本資料夾。
