# 運動熱量估算

行動裝置程式設計課程練習。選擇運動項目，依內建消耗率、體重與時間計算熱量，練習 Spinner 與數值輸入。

## 程式導覽

| 檔案 | 內容 |
|---|---|
| [MainActivity.java](app/src/main/java/tw/cgu/b0929035/ch06_energycalculator/MainActivity.java) | 主要畫面與事件處理。 |
| [activity_main.xml](app/src/main/res/layout/activity_main.xml) | 畫面配置。 |

## 開發環境

Java 8 語法、Android Gradle Plugin 7.2.1、Gradle 7.3.3，compile／target SDK 32，最低 SDK 26。使用 Android Studio 開啟本資料夾。
