# webp

這裡放的是我大學網頁設計課程的作業和 Lab，內容從 HTML、CSS 開始，接著練習 JavaScript、jQuery、API 串接和 React。

## 作業

| 資料夾 | 內容 |
| --- | --- |
| [hw1](hw1/) | 角色介紹頁，練習 HTML、CSS 與 media query。 |
| [hw2](hw2/) | 在介紹頁加入 Google Analytics 追蹤碼。 |
| [hw3](hw3/) | 隨機產生字母，透過鍵盤輸入消除字母的打字練習。 |
| [hw4](hw4/) | 用 jQuery 動畫製作多軌打字遊戲。 |
| [hw5](hw5/) | 串接桃園機場捷運資料，顯示站名、票價與行車時間。 |
| [hw6](hw6/) | HTTP、Cookie、CORS 的心得文章。 |
| [hw7](hw7/) | 練習拆分 React 元件，製作登入畫面。 |
| [hw8](hw8/) | 使用 React 與 Material UI 製作登入畫面。 |

## Lab

| 資料夾 | 內容 |
| --- | --- |
| [qz1](qz1/) | 點擊按鈕後修改標題與段落文字。 |
| [qz2](qz2/) | 修改頁面文字，並動態新增按鈕。 |
| [qz3](qz3/) | 監聽鍵盤事件，將輸入的字元顯示在頁面上。 |
| [qz4](qz4/) | 用 jQuery 處理按鈕事件與文字修改。 |
| [qz5](qz5/) | 動態新增清單項目，處理清單的點擊事件。 |
| [qz6](qz6/) | 用 JavaScript 與 jQuery 顯示即時時鐘。 |
| [qz7](qz7/) | 讀取臺北市雨量資料，顯示測站、時間與雨量。 |
| [qz8](qz8/) | 練習 React 元件，產生多個按鈕並處理點擊事件。 |

## 執行方式

一般 HTML 作業可直接用瀏覽器開啟各資料夾內的 HTML 檔案。

`hw7`、`hw8`、`qz8` 是 React 專案。先安裝 Node.js，再進入對應的資料夾（例如 `webp/hw7`）執行：

```bash
npm install
npm start
```
